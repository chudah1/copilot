# PenKeep Stickiness Phases

The current foundation is in place: positions, reasons/theses, monitoring, review flows, decision snapshots, open follow-ups, and behavioral memory now connect into one product flow.

## Remaining phases

### 1. Make the weekly return loop unavoidable

- Turn the weekly digest into a short action queue, not an archive of information.
- Show what changed, why it matters to the user's own view, and the one decision to make next.
- Carry unfinished follow-ups into the next review until the user closes or dismisses them.
- Success signal: users return weekly and complete at least one meaningful review.

### 2. Close the evidence-to-decision loop

- Make every important monitoring event resolve into a clear action: reaffirm, lower confidence, rewrite, or exit.
- Show the outcome of prior decisions when the same assumption is tested again.
- Keep supporting evidence quiet and reserve attention for evidence that changes the decision.
- Success signal: fewer unresolved reviews and more decisions recorded while evidence is fresh.

### 3. Turn behavioral memory into a product advantage

- Surface portfolio-level patterns at the moment they can change behavior, not only in quarterly review.
- Compare prompted decisions with eventual outcomes and explain the pattern in plain language.
- Give users a small, specific intervention before adding, selling, or dismissing evidence.
- Success signal: users act on a personal pattern insight and return to see whether it held up.

### 4. Make monitoring trustworthy and current

- Ground generated checks in current filings, earnings, market data, and cited sources.
- Make provider fallbacks, stale data, missing data, and AI-credit failures visible without breaking the workflow.
- Show exactly what each check watches, when it was last evaluated, and why it reached its verdict.
- Success signal: users trust an alert enough to review it instead of treating the product as another noisy feed.

### 5. Tighten activation and expansion

- Get a new user from import to one confirmed, monitored position as quickly as possible.
- Use the first useful review to invite the next holding, digest, or decision checkpoint.
- Keep the dashboard value-first for users who arrive without a written thesis or reason.
- Success signal: users complete one monitored position, then voluntarily add another or return for the next review.

### 6. Instrument PMF before adding more surface area

- Track activation, first monitored position, first evidence review, first decision, weekly return, and follow-up closure.
- Segment these metrics between thesis-driven and hearsay-driven users.
- Use real behavior to decide which workflow deserves deeper investment before expanding features.
- Success signal: retention and completed decision loops improve for a clearly defined first user segment.
